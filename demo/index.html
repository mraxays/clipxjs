The clipboard, without the boilerplate.

Copy, cut, paste and format text using plain HTML attributes. Toast feedback is built in, and no dependencies are required.

npm i clipxjs
<button
  data-clipx-target="#email"
  data-clipx-format="trim,lowercase"
  data-clipx-msg="Copied">
  Copy email
</button>

<script> new ClipX().attach(); </script>

Try it

Everything below is live. Each control is just an HTML element with data attributes.

01

Copy

Copy from any element with data-clipx-target, or copy fixed text with data-clipx-text.

02

Cut

Add data-clipx-cut to copy and then clear the source element.

03

Paste

data-clipx-paste fills an element from the clipboard. It needs HTTPS and the browser's permission.

04

Format

Chain formatters with data-clipx-format. They run left to right before the text is copied or pasted.

Attributes

The whole API for the common case.

data-clipx-target
Selector of the element to copy or cut from.
data-clipx-text
Static text to copy.
data-clipx-paste
Selector of the element to paste into.
data-clipx-cut
Clear the target after copying.
data-clipx-format
Comma list: trim, uppercase, lowercase, capitalize, titlecase, collapse, singleline, striphtml.
data-clipx-msg
Custom success message.
data-clipx-toast
Show only the toast and leave the button text alone.
data-clipx-disable-msg
Don't change the button text.
data-clipx-disable-toast
Don't show the toast.
data-clipx-toast-position
"top" or "bottom" (default).
data-clipx-duration
Milliseconds the message stays visible (default 1500).
